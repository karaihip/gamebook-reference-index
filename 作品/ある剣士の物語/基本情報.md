## プレイ特性

| 項目          | 評価  | コメント                                                                    |
| ----------- | --- | ----------------------------------------------------------------------- |
| 難易度         | 中   | ルール自体は簡潔だが、適切なルートや行動、持ち物を見つけることで攻略しやすくなる                                |
| 初見クリア可能性    | 低～中 | 初回でクリアする可能性はなくはないが、適切な選択や持ち物を知らない状態ではランダム判定に頼る場面が増える                           |
| リトライ前提度     | 高   | 失敗したルートや判定結果を踏まえ、別ルートや別の行動を試すことが攻略につながる                                 |
| 戦闘比重        | 低   | 一般的な能力値を用いた戦闘システムはない。ただし敵がいないわけではない                                |
| 運要素         | 中～高 | D6を振る機会は比較的多い。ただし、適切な持ち物を得たり正しい行動を選んだりすることで、ランダム判定そのものを回避したり成功率を高めたりできる場面もある |
| パラメータ管理     | なし  | 主人公の能力値などを継続的に管理する必要はない                                                 |
| 持ち物・キーワード管理 | あり  | 所持している物によって、ランダム判定を回避できたり、より有利な選択肢を取れたりする                               |
| マッピング / メモ  | 推奨  | 公式には筆記具不要。ただし複数回プレイすると、現在のプレイで得た持ち物と過去のプレイで得た物を混同しやすいため、簡単な記録があると遊びやすい  |
| 主人公タイプ      | 自由型 | 主人公は剣士であること以外、人物像が強く規定されていない                                            |

## ゲームシステム

本作では主人公の能力値を作成・管理する必要はなく、一般的な戦闘ルールも存在しない。

一方、D6によるランダム判定は比較的頻繁に登場する。

ただし、全てが単純に運の良し悪しだけで結果が決まるというわけでもない。

特定の持ち物を入手していればランダム判定そのものを避けられたり（すぐなくなるが）、適切な行動を選べば有利な条件で進められる、逆に不適切な選択をすると成功確率の低い判定を要求される、といった構造になっている。

また、行動選択を誤っても、ランダム判定に成功すれば状況を立て直せる場合もある。

いわゆる「真の道」をみつければ、ほぼランダムにかかわることなくクリアできるようになるが、どちらかというと「正解ルートを一本だけ探す」というより、別の道や別の行動を試しながら、好きなルートやら安定して進める方法を探すことにも意味がある。

## 構造上の特徴

本作では、リトライによって得られた知識が、その後のプレイを直接有利にする。

一度失敗した場面でも、

* 別の経路を通る
* 必要な持ち物を入手してから進む
* より有利になる行動を選ぶ
* 危険なランダム判定を回避する

といった方法を試すことができる。

単純な一本道の「正解」を探すだけではなく、異なる攻略過程を試せる点は、本作を含むゲームブック温故屋作品の特徴の一つといえる。

一方で、一部の攻略要素については「一度正解を知れば、以後のプレイでもその知識をそのまま利用できる」性質が強い。

そのため、初回プレイでは試行錯誤として機能していた仕掛けが、答えを知った後にはほぼ障害にならなくなる場合がある。

これはリトライによる知識蓄積を重視する構造の裏返しでもあるが、再プレイ性という点では若干気になる部分でもある。

## プレイ時に要求される要素

分類コード：**MLKF**

* **M：Mapping** — 過去に通った経路や選択を把握しておくと攻略しやすい
* **L：Luck with Dice** — D6判定が比較的頻繁に発生する
* **K：Keyword Management** — 持ち物の有無が攻略に大きく影響する
* **F：Flair / Insight** — 状況から、より有利な行動や使うべき持ち物を判断する

ただし、これらの重要度は固定ではない。

探索によって適切な持ち物や行動を発見すると、それまで運に頼っていた場面を安定して突破できることがある。

そのため本作では、**ダイス運そのものよりも「どうすればダイスを振らずに済むか、あるいは有利な条件で振れるか」を発見すること**が攻略上重要となる。
