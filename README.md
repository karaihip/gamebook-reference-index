# Gamebook Reference Index

ゲームブックに関する情報を整理・蓄積し、参照しやすい形で公開するためのプロジェクトです。

ゲームブックそのものを収集・公開するアーカイブではなく、作品について調べたり、次に遊ぶ作品を探したりするための**参照情報の索引**を目指します。

## 目的

ゲームブックは、現在では入手困難な作品や、Web上にまとまった情報が少ない作品も多く存在します。

本プロジェクトでは、そうした作品についての情報を可能な範囲で整理し、後から人や検索エンジン、各種ツールなどから参照できる形で残していくことを目的とします。

特に、作品内容の重大なネタバレを避けながら、

* どのようなタイプのゲームブックか
* どの版・形式で刊行されているか
* どのような特徴があるか
* 既知のエラッタや注意点があるか
* 関連する資料やWebサイトが存在するか
* どのような作品を好む人に向いているか

といった情報を参照できるようにすることを想定しています。

## 収録予定の情報

作品ごとに、必要に応じて以下のような情報を扱います。

* タイトル
* 著者・訳者・イラストレーターなど
* 出版社
* 刊行年
* ISBN等の書誌情報
* シリーズ
* 版・フォーマット
* 電子書籍版・復刊版などの情報
* ジャンルやゲームシステム上の特徴
* 難易度やプレイ傾向
* ネタバレを避けた紹介
* エラッタ・既知の問題
* 関連資料
* 外部サイトへのリンク
* 感想・コメント
* その他、作品を調べる際に有用と思われる情報

項目やデータ形式は、実際に情報を蓄積しながら変更する可能性があります。

## ネタバレについて

基本的には、作品を未プレイの人が参照できることを重視します。

重大な展開、正解ルート、謎の答えなどについては、通常の紹介情報とは分離して扱う方針です。

攻略情報や詳細な分析を扱う場合には、ネタバレを含むことが明確に分かる形にします。
