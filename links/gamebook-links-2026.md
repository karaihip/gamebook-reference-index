# ゲームブック関連リンク集（2026年版・初稿）

最終確認日：2026-09-03

日本語圏を中心に、ゲームブックを調べる・探す・遊ぶ・作る際の入口になるWebサイトをまとめたリンク集です。

これはゲームブック本文やスキャンデータを収集する一覧ではありません。書誌、紹介、研究、攻略、エラッタ、出版社・制作者など、ゲームブックについての参照情報を対象とします。

## 状態表示

- **現役**：最近の更新、または現在提供中のサービス・刊行物を確認できたもの
- **閲覧可**：更新停止を含むが、主要な内容を現在も閲覧できるもの
- **要追跡**：旧リンク集には記録があるが、現URLでの閲覧・移転先を確認できていないもの
- **アーカイブ**：原則として保存サービス上でのみ閲覧できるもの（本初稿では候補のみ記載）

状態はサイトの価値や権利状態を示すものではありません。また、各ページに含まれる本文・画像等の利用条件は、それぞれのサイトで確認してください。

## まず見る入口・総合データベース

### [ゲームブック倉庫番 @ Wiki](https://w.atwiki.jp/gamebooklist/)

- 状態：**閲覧可**
- 種別：書誌・作品一覧
- 言語：日本語
- 日本で発売されたゲームブックを、主に出版社別で一覧化。作家別・年代別の入口もある。
- 元サイト「ゲームブック倉庫番」のデータを運営者の同意を得て移植したもの。トップページに、データは基本的に転載・流用可である一方、個別書籍の概要等には権利上の注意が必要と明記されている。
- トップページの表示上の最終更新：2009-05-08。

### [ゲームブックの情報論](https://www.syugo.com/4th/pluviose/index.php)

- 状態：**現役**
- 種別：作品・文献データベース、攻略、回顧
- 言語：日本語

- 攻略チャート、最適ルート、人物・用語等を含むページがあるため、未プレイ時はネタバレに注意。
- 2024～2025年付の更新を確認。

## 今後の追加方針

1. 現存する旧リンク集から全リンクと説明文を抽出する。
2. 元URLへの到達可否、HTTPS化、ドメイン失効、移転告知を確認する。
3. サイト名・管理者名・特徴的な記事名で移転先を検索する。
4. 見つからない場合はInternet Archive等の保存状況を確認する。
5. 各サイト内のリンク集から、現在の検索では発見しにくいサイトを追加する。
6. 作品別ページから参照する場合に備え、シリーズ名・著者名・ネタバレ有無をタグ化する。

## 掲載候補の記録項目

将来、MarkdownからCSV・YAML・JSON等へ移す場合は、最低限次の項目を持たせる。

```yaml
- title: サイト名
  url: https://example.com/
  language: ja
  categories:
    - bibliography
    - review
  scope:
    - fighting-fantasy
  spoiler: mixed
  status: active
  last_checked: 2026-09-03
  description: 簡潔な説明
  notes: 移転・文字化け・権利関係など
```

## 免責と情報提供

- 掲載は内容の全面的な推奨や保証を意味しない。
- リンク先の権利、利用条件、公開範囲は各運営者に帰属する。
- 違法に公開された可能性のある書籍本文・スキャンへの誘導は対象外とする。
- 閉鎖、移転、説明の誤り、追加すべきサイトがあれば、確認可能な情報とともに修正する。
